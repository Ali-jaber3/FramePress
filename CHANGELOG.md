# Changelog

## v0.1.0 — First public release

- Native Windows 11 app with editable C# / WPF source and .NET 10.
- One-step recursive search and compression with per-resolution profiles.
- CPU/GPU name display and automatic short-sample encoder benchmarks.
- NVIDIA NVENC, Intel QSV, AMD AMF and CPU choices, with safe CPU fallback.
- Actual before/after sizes and reduction per completed file; output-size visibility option.
- Optional image compression, ten languages, Arabic RTL and dark/light appearance.
- Copy mode, recovery backups, validation, cancellation and CSV reports.
- NSIS installer and GitHub Actions Windows build/render checks.

Earlier local prototype numbers were development iterations, not public GitHub releases. The first public application/package version is 0.1.0.
